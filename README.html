Quiz Informatique

Un mini-jeu de quiz interactif développé en HTML, CSS et JavaScript (sans framework), permettant à l'utilisateur de tester ses connaissances en informatique avec des questions à choix multiples.

Fonctionnalités

  • Sélection de la difficulté : facile, moyen, difficile
  • Questions issues de l'API Open Trivia DB
  • Compte à rebours de 15 secondes par question
  • Score affiché en temps réel
  • Affichage de la bonne réponse
  • Musique de fond jouée pendant le quiz
  • Boutons pour quitter, rejouer et ouvrir la notice du jeu
  • Interface responsive et accessible

Arborescence du projet

  Info Quiz/
  ├── index.html
  ├── assets/
  │   └── background-music.mp3
  └── README.txt

Fonctionnement du jeu

  1. Cloner le projet :
    git clone https://github.com/KUISSI/Info-Quiz.git
  2. Ouvrir le fichier index.html dans ton navigateur :
    Aucune installation n’est requise.

Règles du jeu

  1. Sur l'écran d'accueil, sélectionnez un niveau de difficulté.
  2. Cliquez sur Commencer pour lancer la partie.
  3. Une question avec 4 réponses s'affiche.
    • Vous avez 15 secondes pour répondre.
    • Cliquez sur une réponse pour la valider.
    • Le bouton Question Suivante s’affiche ensuite.
  4. À la fin des 10 questions, votre score final est affiché.
  5. Vous pouvez ensuite rejouer ou quitter à tout moment.

Musique de fond

  • Fichier : background-music.mp3
  • Licence : libre de droits (ex : Bensound, Free Music Archive)
  • La musique est jouée automatiquement lors du quiz.
  • Vous pouvez changer le fichier dans le dossier /assets/.

Technologies utilisées

  • HTML5 – structure du contenu
  • CSS3 – styles et mise en page
  • JavaScript (ES6) – logique du jeu, DOM, POO
  • API Open Trivia DB – génération dynamique de questions
